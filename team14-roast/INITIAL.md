# INITIAL.md - Team14-Roast Product Definition

> Paste a GitHub link, get a funny AI roast of the profile or repo. Just for fun.

---

## PRODUCT

### Name
Team14-Roast

### Description
A fun web app where a user pastes a public GitHub profile or repository link and receives a humorous, good-natured "roast" generated by an LLM from public GitHub data (repo names, languages, commit messages, README quality, stars, etc.). Roasts can be shared and reacted to.

### Target User
Developers and students who want a laugh and a shareable roast of their own (or a friend's) GitHub.

### Type
- [x] SaaS (free, consumer fun app)

### Content Rules
- Roast the **code, repos, and public activity only**. Never roast personal attributes (appearance, race, gender, religion, nationality, health, etc.).
- Intensity levels: Mild, Medium, Spicy. Spicy is still playful, never abusive.
- Only public GitHub data is read. No GitHub login required for the target.

## MODULES

### Module 1: Authentication (Required)

**Models:**
- User: id, email, hashed_password, full_name, is_active, is_verified, oauth_provider, created_at
- RefreshToken: id, user_id, token, expires_at, revoked

**Endpoints:**
- POST /auth/register, /auth/login, /auth/refresh, /auth/logout
- GET /auth/me, PUT /auth/me
- GET /auth/google, GET /auth/google/callback

**Pages:** /login, /register, /profile

---

### Module 2: Roasts (Core)

**Description:** Submit a GitHub link, fetch public data, generate and store a roast.

**Models:**
```
Roast:
  - id, user_id (FK, nullable for anonymous)
  - github_url, github_username, target_type (profile|repo)
  - intensity (mild|medium|spicy)
  - roast_text, github_snapshot (JSON)
  - is_public (bool), share_slug (unique)
  - created_at, updated_at
```

**Endpoints:**
```
POST   /api/v1/roasts            - Create roast from GitHub URL
GET    /api/v1/roasts            - List my roasts
GET    /api/v1/roasts/{id}       - Get one
DELETE /api/v1/roasts/{id}       - Delete mine
GET    /api/v1/roasts/s/{slug}   - Public shared roast
```

**Services:** GitHubService (URL validation, public data fetch), RoastService (prompt, LLM call, content-safety guard)

**Pages:**
```
/                  - Landing with URL input + intensity picker
/roasts            - My roast history
/roasts/{id}       - Roast result (copy / share)
/r/{slug}          - Public shared roast
```

---

### Module 3: Gallery and Reactions

**Description:** Public feed of shared roasts with emoji reactions.

**Models:**
```
Reaction:
  - id, roast_id (FK), user_id (FK)
  - emoji (fire|skull|laugh|clap)
  - created_at   (unique: roast_id + user_id + emoji)
```

**Endpoints:**
```
GET    /api/v1/gallery                 - Public roasts (paginated, sort: new|top)
POST   /api/v1/roasts/{id}/reactions   - Add reaction
DELETE /api/v1/roasts/{id}/reactions/{emoji} - Remove reaction
```

**Pages:** /gallery

---

### Module 4: Dashboard (Analytics)

**Endpoints:** GET /api/v1/dashboard/stats (roasts per day, top languages roasted, intensity split, reactions received)

**Pages:** /dashboard, /settings
